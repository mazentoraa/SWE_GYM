# Engineering Gym

A vibe-coded interactive six-month study guide for preparing for a Software Engineer role. It helps you strengthen engineering fundamentals.

Do not look at the written code. it's shameful. but anyway, it works.

## How to use

1. Open `index.html` in your browser.
2. Use **Roadmap** to follow the 24-week plan, or **Topic library** to study any subject in any order.
3. Use **Daily gym** for a short problem-solving and recall session.
4. Use **Interview lab** to answer questions before revealing the reference points.
5. Save difficult concepts in **Notes & review**.
6. Mark checkpoints complete only when you can explain or demonstrate them without help.

Progress is saved in your browser on that device. Use **Export progress** to back it up as JSON, and **Import progress** to restore it later.

Learning links require an internet connection. The guide itself runs locally; no account or server is needed.

Open for improvements.
